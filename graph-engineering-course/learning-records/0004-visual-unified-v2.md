# 기존 코스의 추상성과 시각 부족이 확인되어 v2 미션을 확장했다

사용자는 2026-07-29 기존 Graph Engineering 토픽이 “이미지나 설명이 내가 이해하기에는 부족하다”고 명시했고, X 북마크 원문을 전부 구체적으로 살펴 AI Agents in Depth 코스처럼 시각적·완결된 학습자료로 재구성해 달라고 요청했다. 따라서 코스 범위를 기존 개선 그래프+실행 그래프에서 문제 트리·개선 거버넌스·실행 오케스트레이션·지식/시간 그래프의 네 감각과 출처 검증까지 확장한다.

**Evidence**: 245개 북마크 전수 수집, 관련 X 원문 9개 확보, 4개 전문 synthesis와 primary-source evidence ledger 생성.

**Implications**: 향후 레슨은 코드 중심이 아니라 대형 모식도, 실제 사용자 시스템 사례, 회수 퀴즈로 구성한다. X 정량 주장은 공식 근거와 범위를 확인하지 않으면 사실로 가르치지 않는다.
