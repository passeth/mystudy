# 선행 지식: 사용자는 에이전트 실무자다 (코스 시작 시점)

사용자는 Aside(에이전트 브라우저)의 헤비 유저이자 빌더다: 자체 스킬(glovv, erp-sales-hx-daily 등 20개+)을 작성하고, cron/heartbeat 루틴을 운영하며, 서브에이전트 병렬 오케스트레이션을 일상적으로 쓰고, MEMORY.md 계층 메모리를 가진 시스템을 매일 사용한다. RISELAB/trade-intel 등 에이전트를 내재화한 SaaS도 직접 개발한다.

**Evidence**: 2026-07-27 이 코스의 레슨 생성 과정 자체가 5개 fork_self 서브에이전트 병렬 distillation + 5개 병렬 레슨 authoring으로 수행됐다.

**Implications**: 기본 개념(ReAct, tool calling, 프롬프트 작성)을 입문자 수준에서 다시 가르치지 않는다. 대신 (a) 책의 명명된 프레임워크와 수치(하네스 5기능, 6압축 전략, Pass@k vs Pass^k 등)로 기존 직관을 '이름 있는 지식'으로 격상시키고, (b) 사용자가 아직 안 핀 것(체계적 평가, 통계적 유의성, verifier 설계, 지속 진화 루프)을 ZPD 후방으로 둔다. 레슨 8(평가)과 9(진화)가 이 사용자의 가장 큰 갭일 가능성이 높다.
