2. 스킬 패키지 내용물 (우리 정의)

  MISSION.md          # 닫을 결정
  ontology.slice.md   # 최소 엔티티·제약
  tools.md            # 허용 도구·쓰기 권한
  checks.md           # judge / 금지 패턴
  examples/           # decision traces 샘플
  prompts/            # 고정 시스템 지침

Aside skill, Claude skill, 내부 패키지 — 형식은 달라도 결정 단위로 묶는다는 원칙은 같다.

더 똑똑한 범용 에이전트를 키우다 보면 온톨로지·권한이 흐려진다. 스킬 경계가 곧 안전 경계다.
