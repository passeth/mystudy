allow / restrict / forbid를 표로 고정하고, 위험 문장은 순화안까지 남긴다.

오늘의 한 줄
같은 성분·같은 문장이어도 Country가 바뀌면 Claim.status_in이 바뀐다.

1. 판정 연습 표 (교육용 모범 답안)

실제 출시 전 규제/법무 검토 필수. 여기서는 사고 경로를 고정합니다.

ClaimKREUUS공통 Reason 키

2. restrict일 때 하는 일

  • 문장 폐기만이 아니라 suggested_fix를 남긴다.
  • 예: C2 → “모공이 없어져 보이게” / “look of pores” 계열로 순화 제안
  • 어떤 규칙 ID가 발화했는지 trace에 기록

3. reference class 한 방울

C3는 “미백 키워드가 시장에서 강하다”는 평균 인사이트(99%)에 속해도, 치료 언어 + 색소 질환 암시라는 1% 치명 클래스일 수 있습니다. Kollegger 토크의 reference class validation을 여기 적용하세요.

4. 미니 실습

  1. C2를 세 시장 각각에 맞게 순화 문장 1개씩 쓰세요.
  2. C3를 완전히 버릴지, 증거 확보 후 약한 톤으로 내릴지 선택하고 이유 한 줄.
  3. “인사이트가 강해서 allow”라고 말한 문장을 찾아 교정하세요. (자기 초안 포함)
