2. 핵심 교정 카드 7선

교정

GraphRAG “18%/85%”

Microsoft GraphRAG의 보편 성능이 아니라 2026년 ChatP&ID 논문의 산업 도면(P&ID) 도메인 결과이며, accuracy와 cost의 대조군도 서로 다르다. 별도 도메인 사례로 격리해서 가르친다.

교정

Bun vs Python→TypeScript

Bun은 Zig→Rust 마이그레이션(공식·1,448 files)이고, 165k LOC Python→TypeScript 포트는 이름이 공개되지 않은 별도 Anthropic 내부 프로젝트다. 하나의 사례처럼 합치지 않는다.

범위 명시

Anthropic 90.2%

Opus 4 lead + Sonnet 4 subagent 구성이 단일 Opus 4 대비 내부 research eval에서 90.2% 우위였다. 공개 범용 벤치마크의 일반 향상률이 아니다.

범위 명시

토큰 4배/15배

Agent는 채팅 대비 약 4배, 멀티에이전트는 약 15배 토큰을 쓴다는 관측이다. 성능 배수가 아니라 비용 배수이며 고가치 breadth-first 리서치에만 적용한다.

교정

AutoGen 현재 상태

AutoGen은 공식적으로 Maintenance Mode이고 GraphFlow는 experimental이다. Microsoft의 현재 주력은 Microsoft Agent Framework(MAF) 1.0 GA다. 신규 채택 예제는 MAF 기준으로 짠다.

라이선스 정정

GitNexus 라이선스

PolyForm Noncommercial 1.0.0이다. “오픈소스”가 아니라 source-available/noncommercial로 가르치고, 상업적 사용 전 라이선스 검토를 명시한다.

의미 정정

“중단 지점에서 재개”의 실제 의미

LangGraph는 super-step 체크포인트 이후 노드 처음부터 재실행(idempotency 필요)되고, Claude Code dynamic workflows는 같은 세션 안에서만 resume되며 새 세션은 fresh start다. 둘 다 “영구 재개”와 동일시하지 않는다.
