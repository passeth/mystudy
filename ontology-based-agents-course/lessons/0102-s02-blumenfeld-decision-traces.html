1. 토크 논지

  • Context graph 논의(Foundation Capital 등)의 실무 핵은 decision traces
  • KB/RAG만으로는 “정확해 보이는 일반론”에 머물기 쉬움
  • 트레이스 = 과거 결정 + 추론/이유 + 유사 케이스 결과
  • 금융 분석 에이전트 비유: 위험 요인 문서 vs 거절/승인 근거 그래프

You can think of us like a knowledge layer graph database at the core.

So, I'm going to talk to you today about context graphs.

가져올 것

  • Decision·Reason·Evidence·Outcome 구조
  • 유사 케이스 검색이 다음 행동의 입력
  • 문서와 트레이스를 같은 그래프에 연결

남길 것 / 경계

  • 모든 로그를 트레이스라고 부르는 것
  • 트레이스 없이 “설명 가능한 에이전트” 주장

2. 우리 파이프라인 번역

RISELAB · claim-review

  • 클레임 거절/수정 사유를 Decision trace로 저장
  • 유사 성분·국가 조합 검색

Trade Intel · reorder-risk

  • 재주문 보류/선연락 결정과 결과(주문 여부) 저장
  • 다음 주 스캔 시 유사 바이어 경로 조회
