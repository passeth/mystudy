2. 규칙 발화 시뮬레이션

C1 × EU
  rules fired: none critical
  → allow (human 최종 확인)

C2 × US
  rules fired: absolute_or_erase_risk
  → restrict + suggested_fix

C3 × any
  rules fired: therapeutic_or_disease_language
  → forbid | needs_human
  → prior similar forbid traces escalate

3. 시장 인사이트 Evidence 연결

인사이트 PDF/노트가 있다면:

Evidence:EV-mkt-2026q1
  kind: market_note
  summary: "미백 키워드 CTR 높음"
Claim:C3 -inspired_by-> Evidence:EV-mkt-2026q1   # 선택 관계
# 그러나 inspired_by ≠ allowed_by
혼동 금지
inspired_by(인사이트)와 supported_by(규제·효능 증거)를 같은 엣지로 쓰지 마세요.

4. 미니 실습

  1. C2×EU 경로를 노드 5개 이상으로 손으로 그리세요.
  2. 발화 규칙 이름을 스스로 2개 붙이세요. (영문 snake_case)
  3. 인사이트 Evidence를 붙이되 allow 근거로 쓰지 않았음을 한 줄로 명시.
