REFERENCE · GLOSSARY

시각·실무 용어집

Definitions used across the course.

레슨 전 구간에 공통으로 쓰는 용어. 충돌하면 이 정의가 우선한다.

Ontology (온톨로지)

도메인에서 무엇이 존재하고 어떤 관계가 허용·금지되는지 명시한 규약. 사전 이상, playbook.

Domain graph

온톨로지 인스턴스 데이터. 실제 제품·성분·바이어 노드.

Playbook ontology

에이전트 행동을 안내하는 제약/규칙이 포함된 온톨로지 사용법(Barrasa).

Decision trace

결정·이유·근거·결과·시점의 구조화 기록.

Context graph

문서/엔티티/결정 트레이스를 연결해 행동 맥락을 제공하는 그래프.

Reference class validation

일반 규칙을 적용하기 전, 이 케이스가 속한 집단/예외를 확인하는 절차.

Graph memory

관계가 순회 가능한 장기 기억. 토큰 덤프와 구분.

Temporal edge

valid_from/valid_to를 가진 관계. 무효화로 이력 보존.

Invalidate-don't-delete

과거 사실을 지우지 않고 끝내기. Graphiti 감각.

Provenance

사실/결정의 출처. 문서, 사람, 도구, 시간.

Skill

한 결정에 필요한 온톨로지 슬라이스·도구·검사·예시를 묶은 패키지.

Scaffolding

모델·툴·루프 등 에이전트 골격. 표준화되는 층.

Harness

에이전트를 둘러싼 상태·권한·보고·재시도 장치. 실패의 많은 원인.

Loop engineering

목표-관측-오차-보정의 제어 루프 설계.

HITL

Human in the loop. 외부 side effect 전 사람 승인.

Judge-first

산출물 생성 전에 검증 기준/검사기를 먼저 정의.

GraphRAG

지식그래프를 활용한 검색증강. 문서 RAG의 보완재인 경우가 많음.

Hybrid retrieval

벡터/문서 + 그래프 경로를 역할 분담으로 함께 사용.

Entity resolution

에바스/EVAS/evas.business처럼 같은 실체의 이름 변형을 하나로.

Side effect

외부에 영향을 주는 쓰기(메일, ERP 반영, 결제). 기본 잠금.
